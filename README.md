# 🌸 佐倉市紹介ウェブサイト

このリポジトリは、**千葉県佐倉市**の歴史、観光スポット、および主なイベントを紹介するレスポンシブなウェブサイトのソースコードを含んでいます。

## 🏛️ プロジェクトの目的

* 佐倉市の豊かな歴史的魅力と自然景観を訪問者に伝える。
* HTML, CSS, JavaScriptを使用したモダンなフロントエンド開発の基礎を実践する。
* Intersection Observer APIを用いた**スクロール時のフェードインアニメーション**を実装する。

## 🌟 特徴

* **レスポンシブデザイン**: モバイルデバイスからデスクトップまで、表示が最適化されます。
* **動的なイベントリスト**: JavaScriptでイベントデータを管理し、HTML要素を動的に生成します。
* **スムーズなユーザー体験**: CSS TransitionとJavaScriptのIntersection Observerによる滑らかなフェードインエフェクト。
